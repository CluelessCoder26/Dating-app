# Swipe Experience Documentation

## Overview
The interaction design and technical implementation of the swiping mechanism.

## Technical Details
- **Libraries**: `react-use-gesture` and `@react-spring/web`.
- **Physics**: Spring configurations for realistic drag and release physics.
- **Thresholds**: Specific distance and velocity thresholds to trigger a like or pass.
- **Haptics**: Integration with the Capacitor Haptics API for mobile devices.
