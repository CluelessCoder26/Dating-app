# Premium Discovery Features Documentation

## Overview
Features available only to premium subscribers.

## Features
- **Rewind**: Undo the last swipe.
- **Super Likes**: Send a highlighted like.
- **Passport**: Change location to swipe anywhere in the world.
- **See Who Liked You**: Access to the "Likes You" grid.

## Paywalls
Interception UI when a free user attempts to access premium features.
