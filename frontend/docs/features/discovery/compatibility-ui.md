# Compatibility UI Documentation

## Overview
Visualizes the compatibility score and matching traits between the current user and the potential match.

## Elements
- **Compatibility Score**: Circular progress or badge indicating percentage.
- **Shared Interests**: Highlighted common tags.
- **Astrological Compatibility**: Visual indicators if applicable.

## Styling
Dynamic color coding based on score thresholds (e.g., green for >90%, yellow for >70%).
