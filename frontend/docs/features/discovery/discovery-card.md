# Discovery Card Documentation

## Overview
The Discovery Card is the primary UI element displaying a potential match's profile information, photos, and compatibility metrics.

## Features
- Interactive photo gallery (tap to next/prev).
- Profile summary (name, age, location).
- Prompts and answers.
- Swipe gestures (left/right/up) using Framer Motion or React Spring.

## Accessibility
- ARIA labels for swipe buttons.
- Keyboard navigation support.
