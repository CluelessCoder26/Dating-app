# Match Celebration Documentation

## Overview
The UI/UX flow that occurs when a mutual like is established.

## Flow
1. **Trigger**: WebSocket event or immediate API response indicating a match.
2. **Animation**: Confetti, dramatic scaling, or custom Lottie animation.
3. **Actions**: Options to "Send a Message" or "Keep Swiping".

## Assets
- Confetti library: `react-confetti`.
- Custom Lottie files for match graphics.
