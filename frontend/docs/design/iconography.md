# Iconography

We use **Lucide React** for our icon set. It provides a clean, consistent, and highly readable set of SVG icons.

## Usage Rules
- **Consistency**: Always use Lucide React icons. Avoid mixing icon sets.
- **Stroke Width**: Maintain a consistent stroke width, typically `2px`.
- **Colors**: Icons should inherit the text color by default (`currentColor`), allowing them to be styled via text color utilities.

## Sizing
Use a standard scale for icon sizes to match the typography scale:
- `sm`: 16px (Inline with small text)
- `base`: 20px (Default for most buttons and UI elements)
- `md`: 24px (Standard standalone icons)
- `lg`: 32px (Empty states, large UI indicators)
- `xl`: 48px (Hero sections, prominent illustrations)
